Why Greedy + DSU Outperforms Baselines:

  • Greedy (by Profit): Treats the system as an independent system / matroid. By greedily prioritizing highest-paying jobs and placing them as late as possible ($\le$ deadline), it frees up early slots for other jobs, guaranteeing the mathematically optimal total profit.
  • Earliest Deadline First (EDF): Prioritizes jobs purely based on deadline urgency regardless of profit, frequently filling slots with low-value jobs and blocking high-value jobs.
  • First-Come First-Served (FCFS): Disregards both deadlines and profit, leading to severe profit loss and high rejection rates under heavy loads.

Theoretical Formulation & Algorithm Design

1. Problem Formulation

We are given $n$ unit-time jobs $J = \{j_1, j_2, \dots, j_n\}$ and $m$ identical processors (Cloud Virtual Machines). Each job $j_i$ has a deadline $d_i \in \mathbb{Z}^+$ and an earned profit $p_i \ge 0$. A job yields profit $p_i$ if and only if it completes execution on some processor at or before time slot $d_i$. At most one job can run on processor $p$ during any unit time interval $[t-1, t]$. Our objective is to schedule a feasible subset of jobs that maximizes total profit:

Maximize: ∑_{j \in S} p_j subject to S being feasible on m processors.

2. Disjoint Set Union (DSU) Unrolling Trick

In classical single-processor job scheduling, time slots $1 \dots D$ are indexed directly. For $m$ identical processors, we "unroll" the 2D grid into a 1D timeline of $m \times D$ discrete slots:

Flattened Slot Index i → Time Slot: t = (i // m) + 1, Processor: p = i % m

For a job with deadline $d$, the latest possible slot index is $(d \times m - 1)$. A Disjoint Set Union structure maintains pointers where parent[i] indicates the latest free slot $\le i$. With near-constant amortized time per operation $\alpha(mD)$, finding and assigning the latest valid slot executes in $O(1)$ time.

3. Complexity Analysis

Approach Time Complexity Space Complexity Optimality Guarantee
Greedy + DSU (This Project) O(n log n + m·D) O(m·D) Guaranteed Optimal (Matroid)
Naive Greedy (Linear Slot Search) O(n log n + n·D) O(m·D) Guaranteed Optimal
Earliest Deadline First (EDF) O(n log n) O(m·D) Suboptimal (ignores profits)
Brute-Force Search O(2^n · n log n) O(n) Optimal (Intractable for n > 20)
